## 🚀 كيفية التشغيل

### 1. تشغيل الـ Backend
```bash
cd /workspace/news-platform-backend
npm start
```
الخادم سيعمل على: `http://localhost:3000`

### 2. تشغيل الـ Frontend
```bash
cd /workspace
python3 -m http.server 5500 --directory news-platform-frontend
```
الموقع سيعمل على: `http://localhost:5500`

---

## 🧪 اختبار النظام

### حسابات الاختبار
يمكنك استخدام أي بريد إلكتروني مسجل في قاعدة البيانات لتجربة تسجيل الدخول.

### إنشاء حساب جديد
1. اذهب إلى: `http://localhost:5500/pages/register.html`
2. أدخل البيانات المطلوبة
3. اضغط "إنشاء الحساب"
4. سيتم تسجيل دخولك تلقائياً وتوجيهك للصفحة الرئيسية

### تسجيل الدخول
1. اذهب إلى: `http://localhost:5500/pages/login.html`
2. أدخل البريد الإلكتروني وكلمة المرور
3. اضغط "تسجيل الدخول"

## 🔗 نقاط الاتصال بالـ API

| endpoint | الطريقة | الوصف |
|----------|---------|-------|
| `/api/v1/auth/register` | POST | تسجيل مستخدم جديد |
| `/api/v1/auth/login` | POST | تسجيل الدخول |
| `/api/v1/articles` | GET | جلب المقالات |
| `/api/v1/categories` | GET | جلب التصنيفات |
| `/api/v1/comments` | GET/POST | التعليقات |
| `/api/v1/media` | POST | رفع الوسائط |

## 🛠️ التقنيات المستخدمة

### Backend
- Node.js + Express
- SQLite (better-sqlite3)
- JWT للمصادقة
- Bcrypt لتشفير كلمات المرور
- Helmet للأمان
- CORS للدعم عبر المجالات

### Frontend
- HTML5 + CSS3
- Vanilla JavaScript (ES6+)
- Fetch API للاتصال بالـ Backend
- LocalStorage لحفظ الجلسة
- تصميم متجاوب
