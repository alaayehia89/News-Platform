
## 3. المعمارية البرمجية للـ Backend وخرائط الـ RESTful APIs

### هيكلية المشروع (Folder Directory Structure)

يعتمد تطبيق **Express.js** على نمط معمارية **MVC (Model-View-Controller)** مُحدث مع تقديم طيقة خدمات مخصصة (Service Layer) للتنظيم البرمجي ورفع التكافؤ.

```text
news-platform-backend/
├── config/
│   ├── database.js          # تهيئة الاتصال بـ SQLite
│   ├── helmet.js            # إعدادات أمان Helmet
│   └── constants.js         # الثوابت الموحدة للنظام
├── controllers/
│   ├── authController.js    # تحكم المصادقة والمستخدمين
│   ├── articleController.js # تحكم إدارة المقالات والأخبار
│   ├── categoryController.js# تحكم التصنيفات
│   ├── commentController.js # تحكم التعليقات والتفاعلات
│   ├── ingestionController.js# تحكم الاستيراد الآلي JSON
│   ├── adminController.js   # تحكم الإشراف والمؤشرات
│   └── mediaController.js   # تحكم رفع واستعراض الملفات
├── middlewares/
│   ├── authMiddleware.js    # التحقق من صحة JWT Token
│   ├── roleCheck.js         # فحص الأدوار والصلاحيات (RBAC)
│   ├── uploadMiddleware.js  # تهيئة وتصفية Multer
│   ├── rateLimiter.js       # حماية الحدود المسموحة للطلبات
│   └── errorHandler.js      # التعامل الموحد مع الأخطاء البرمجية
├── models/                  # المخططات والاستعلامات المباشرة لـ SQLite
│   ├── userModel.js
│   ├── articleModel.js
│   ├── commentModel.js
│   └── mediaModel.js
├── routes/                  # تحديد مسارات API RESTful
│   ├── authRoutes.js
│   ├── articleRoutes.js
│   ├── categoryRoutes.js
│   ├── commentRoutes.js
│   ├── ingestionRoutes.js
│   └── adminRoutes.js
├── services/                # إدارات العمليات المعقدة والتكامل الخارجي
│   ├── jsonParserService.js # تحليل واستيراد ملفات JSON
│   ├── cacheService.js      # إدارة ذاكرة التخزين المؤقت المباشرة
│   └── loggerService.js     # كتابة وسجل العمليات system_logs
├── public/
│   └── uploads/             # مجلد استضافة وسائط Multer المقسم تاريخياً
│       ├── images/
│       └── videos/
├── .env.example             # متغيرات البيئة الاسترشادية
├── package.json
└── server.js                # نقطة الانطلاق لتشغيل خادم Node.js

```

### قائمة مسارات الـ API (API Endpoints Table)

#### 1. مسارات المحتوى العام والتصفح (Public Endpoints)

| HTTP Method | API Endpoint | Description | Middlewares المطبقة |
| --- | --- | --- | --- |
| `GET` | `/api/v1/articles` | جلب قائمة الأخبار مع دعم الصفحات والفلترة | `rateLimiter` |
| `GET` | `/api/v1/articles/:slug` | جلب تفاصيل خبر محدد بواسطة Slug | `rateLimiter` |
| `GET` | `/api/v1/articles/breaking` | جلب قائمة الأخبار العاجلة النشطة | `rateLimiter` |
| `GET` | `/api/v1/categories` | جلب الهيكل الكامل للتصنيفات | `rateLimiter` |
| `GET` | `/api/v1/search` | بحث متقدم في المحتوى والوسوم | `rateLimiter` |
| `GET` | `/api/v1/feed/rss` | التغذية الإخبارية بصيغة XML | `rateLimiter` |
| `GET` | `/api/v1/sitemap.xml` | خريطة الموقع الديناميكية لتشجيع SEO | `rateLimiter` |

#### 2. مسارات تفاعل المستخدمين والمصادقة (User Interaction & Auth)

| HTTP Method | API Endpoint | Description | Middlewares المطبقة |
| --- | --- | --- | --- |
| `POST` | `/api/v1/auth/register` | تسجيل حساب جديد لمستخدم عادي | `rateLimiter` |
| `POST` | `/api/v1/auth/login` | تسجيل الدخول وتوليد رمز JWT Token | `rateLimiter` |
| `GET` | `/api/v1/users/profile` | جلب بيانات الملف الشخصي للمستخدم | `authMiddleware` |
| `POST` | `/api/v1/articles/:id/comments` | إضافة تعليق جديد على مقال | `rateLimiter`, `authMiddleware` (Optional) |
| `POST` | `/api/v1/articles/:id/react` | تسجيل تفاعل مع الخبر (Like, etc.) | `rateLimiter` |
| `POST` | `/api/v1/bookmarks/:articleId` | إضافة خبر إلى قائمة المفضلة | `authMiddleware` |
| `DELETE` | `/api/v1/bookmarks/:articleId` | إزالة خبر من المفضلة | `authMiddleware` |

#### 3. مسارات لوحة التحكم والإشراف (Admin & Automation APIs)

| HTTP Method | API Endpoint | Description | Middlewares المطبقة |
| --- | --- | --- | --- |
| `POST` | `/api/v1/admin/articles` | إنشاء مقال جديد | `authMiddleware`, `roleCheck(['Admin', 'Editor', 'Reporter'])` |
| `PUT` | `/api/v1/admin/articles/:id` | تعديل مقال قائم | `authMiddleware`, `roleCheck(['Admin', 'Editor'])` |
| `DELETE` | `/api/v1/admin/articles/:id` | حذف مقال من قاعدة البيانات | `authMiddleware`, `roleCheck(['Admin'])` |
| `POST` | `/api/v1/admin/media/upload` | رفع وسائط جديدة عبر Multer | `authMiddleware`, `uploadMiddleware.single('file')` |
| `POST` | `/api/v1/admin/breaking` | إضافة خبر عاجل جديد مع تحديد المدة | `authMiddleware`, `roleCheck(['Admin', 'Editor'])` |
| `POST` | `/api/v1/admin/ingest/json` | استقبال واستيراد محتوى JSON آلياً | `authMiddleware`, `roleCheck(['Admin'])` |
| `GET` | `/api/v1/admin/analytics` | استخراج إحصائيات وأداء الموقع | `authMiddleware`, `roleCheck(['Admin'])` |
| `GET` | `/api/v1/admin/logs` | استعراض سجلات العمليات والنظام | `authMiddleware`, `roleCheck(['Admin'])` |
