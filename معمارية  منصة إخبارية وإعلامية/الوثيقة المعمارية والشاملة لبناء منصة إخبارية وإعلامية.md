### تصميم ومكونات الصفحات الرئيسية

#### 1. الصفحة الرئيسية (Homepage)

* **CSS Grid / Flex Layout:** هيكل شبكي ديناميكي ينقسم إلى 12 عموداً لضمان تجاوب متكامل مع كافة الشاشات.
* **شريط الأخبار العاجلة (Breaking News Bar):** شريط ثابت (Sticky Component) في أعلى الصفحة بحد أقصى للارتفاع، يعمل عبر WebSocket أو Server-Sent Events / Polling مع خيار إيقاف الحركة عند تحريك الفأرة عليه (Hover to Pause).
* **شبكة البطل الرئيسية (Hero Grid Section):**
* **Main Story (8 Cols):** خبر الرئيسي الأول متضمن صور بدقة عالية، عنوان عريض، ملخص، وزر "تغطية مستمرة" إذا كان الخبر متاحاً للتحديث اللحظي.
* **Side Stories (4 Cols):** قائمة رأسيّة من 3-4 أخبار رئيسية فرعية مع مصغرات صور وعلامات زمنية.


* **كتل الأقسام المخصصة (Category Blocks):**
* **قسم السياسة والمال:** عرض شبكي (3 كروت متساوية مع وسوم الأثر الاقتصادي).
* **الإنفوجرافيك والوسائط:** شريط أفقي قابل للسحب (Carousel / Horizontal Scroll) للصور والفيديوهات مع زر التشغيل السريع (Overlay Play Button).
* **مقالات الرأي (Opinion Column):** كروت دائرية لصور الكُتّاب مع اقتباس عريض من المقال اسم الكاتب.


* **الأكثر قراءة والتفاعل (Trending & Most Read Widget):** تبويب مزدوج Sidebar بين (الأحدث / الأكثر قراءة) مدعوم برقم متسلسل واضح (1 إلى 5) لكل خبر.

#### 2. صفحة تفاصيل الخبر/المقال (Article Detail Page)

* **الترويسة (Article Header):**
* المسار الهيكلي (Breadcrumb): `الرئيسية > سياسة > أخبار محلية`.
* التصنيف الرئيسي، العنوان (H1 عريض وواضح)، العنوان الفرعي (Sub-heading).
* الميتا بيانات: تاريخ ووقت النشر الدقيق، زمن القراءة التقديري، عدد المشاهدات، وزر حفظ الخبر للمفضلة.


* **كارت الكاتب والمصدر:** صورة الكاتب، الاسم، الصفة الوظيفية، رابط الصفحة الشخصية، والمصدر الأساسي إن وجد.
* **الوسيط الرئيسي (Featured Media):** صورة بملء العرض أو مشغل فيديو مدعوم بوصف الصورة (Caption) وحقوق الملكية (Image Credits).
* **المحتوى النصي (Article Body):**
* خطوط طباعية محسّنة للقراءة (Typography Optimized: Line-height: 1.8, Font size: 18-20px).
* كتل اقتباس داخلية (Pull-quotes) شريط تنقل للأقسام الفرعية داخل المقالات الطويلة.
* إدراج الوسائط والإنفوجرافيك والجداول بسلاسة في منتصف النص.


* **شريط المشاركة الاجتماعي (Floating Share Bar):** شريط العائم (أو سفلي للشاشات الصغيرة) يضم: WhatsApp, X (Twitter), Facebook, Telegram, نسخ الرابط، وزر طباعة المقال.
* **الأخبار ذات الصلة (Related Articles):** شبكة من 3-4 كروت تعتمد على الوسوم المتقاطعة (Cross-tagging Algorithm).
* **قسم التعليقات والتفاعلات:**
* **شريط التفاعل السريع (Reactions Bar):** تفاعلات رمزية (إعجاب، إحباط، تحليلي، مهم).
* **صندوق التعليقات:** نماذج لإضافة تعليق، ردود شجرية (Nested Replies)، مع زر الإبلاغ عن سوء الاستخدام (Report Flag).



#### 3. صفحات الأقسام والأرشيف والبحث

* **أعلى الصفحة (Section Header):** عنوان القسم، الأقسام الفرعية التابعة، وشريط التصفح السريع للأخبار العاجلة الخاصة بالقسم.
* **هيكلة الفلترة والبحث:**
* فلترة حسب: النطاق الزمني (اليوم، هذا الأسبوع، أرشيف محدد)، نوع المحتوى (خبر، مقال، تقرير، فيديو)، الكاتب، الوسم.


* **نمط عرض القوائم (Content List Layout):**
* دعم التبديل بين عرض الشبكة (Grid View) وعرض القائمة (List View).
* **آلية التصفح:** اعتماد النمط الهجين؛ تحميل تلقائي للبيانات عند التمرير (Infinite Scroll) مع وضع زر يدوي "تحميل المزيد من الأخبار" لتفادي استهلاك الموارد المفرط وزيادة مرونة استكشاف Footer.



#### 4. لوحة التحكم (Admin Dashboard UI)

* **غرفة الأخبار والتحرير (Editor Center):**
* محرّر نصوص متطور (Rich Text Editor - WYSIWYG) يدعم تنسيق الخطوط، رفع الصور المباشر Drag & Drop، إدراج التغريدات والفيديوهات.
* لوحة خيارات جانبية: تحديد القسم، الوسوم، الجدولة الزمنية، تعديل سلوك SEO (Slug, Meta Title, Meta Description, Canonical URL).


* **وحدة الإدخال والاستيراد الآلي (Auto-Import JSON Hub):**
* واجهة لإدارة جلب المحتوى الآلي من الوكالات والتغذيات الخارجية عبر خوادم API، تستعرض مسودة الأخبار الواردة، ونسب المطابقة تلقائياً مع خيار الاعتماد الفوري أو التعديل قبل النشر.


* **لوحة المراقبة والأداء (Metrics & Control Panel):**
* إحصائيات لحظية لعدد الزوار، المقالات الأكثر قراءة، مع أداة التحكم السريع لتفعيل إيقاف وضع الأخبار العاجلة بضغطة زر.

## 2. هيكلة قاعدة البيانات (SQLite Schema Design)

تعتمد قاعدة البيانات على محرك **SQLite** مع تفعيل قيود المفاتيح الأجنبية (`PRAGMA foreign_keys = ON;`) لضمان تكامل البيانات، وتعيين حقول الفهارس (Indexes) على الأعمدة الأكثر استعلاماً لتوفير سرعة أداء متناهية.

```sql
-- تفعيل المفاتيح الأجنبية لضمان سلامة العلاقات
PRAGMA foreign_keys = ON;

-- ========================================================
-- 1. جدول الأدوار والمستخدمين (Users & Roles)
-- ========================================================
CREATE TABLE roles (
    role_id INTEGER PRIMARY KEY AUTOINCREMENT,
    role_name VARCHAR(50) NOT NULL UNIQUE, -- Admin, Editor, Reporter, User
    permissions TEXT, -- JSON Array formatting permission keys
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE users (
    user_id INTEGER PRIMARY KEY AUTOINCREMENT,
    role_id INTEGER NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    avatar_url VARCHAR(255),
    bio TEXT,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'suspended', 'pending')),
    last_login DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (role_id) REFERENCES roles(role_id) ON DELETE RESTRICT
);

-- ========================================================
-- 2. جدول التصنيفات والوسوم (Categories & Tags)
-- ========================================================
CREATE TABLE categories (
    category_id INTEGER PRIMARY KEY AUTOINCREMENT,
    parent_id INTEGER DEFAULT NULL,
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(120) NOT NULL UNIQUE,
    description TEXT,
    display_order INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (parent_id) REFERENCES categories(category_id) ON DELETE SET NULL
);

CREATE TABLE tags (
    tag_id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(50) NOT NULL UNIQUE,
    slug VARCHAR(60) NOT NULL UNIQUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- ========================================================
-- 3. جدول المؤلفين والمصادر (Authors & Sources)
-- ========================================================
CREATE TABLE authors (
    author_id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER DEFAULT NULL, -- ربط اختياري مع حساب المستخدم
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(120) NOT NULL UNIQUE,
    job_title VARCHAR(100),
    bio TEXT,
    avatar_url VARCHAR(255),
    social_links TEXT, -- JSON Format for social accounts
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE SET NULL
);

CREATE TABLE sources (
    source_id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) NOT NULL UNIQUE,
    slug VARCHAR(120) NOT NULL UNIQUE,
    website_url VARCHAR(255),
    logo_url VARCHAR(255),
    trust_rating INTEGER DEFAULT 5, -- تقييم موثوقية المصدر من 1-5
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- ========================================================
-- 4. جدول الوسائط (Media Center)
-- ========================================================
CREATE TABLE media (
    media_id INTEGER PRIMARY KEY AUTOINCREMENT,
    filename VARCHAR(255) NOT NULL,
    original_name VARCHAR(255) NOT NULL,
    file_path VARCHAR(255) NOT NULL,
    mime_type VARCHAR(100) NOT NULL,
    file_size INTEGER NOT NULL, -- Size in Bytes
    alt_text VARCHAR(255),
    caption TEXT,
    uploaded_by INTEGER,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (uploaded_by) REFERENCES users(user_id) ON DELETE SET NULL
);

-- ========================================================
-- 5. جدول الأخبار والمقالات (Articles / News)
-- ========================================================
CREATE TABLE articles (
    article_id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(255) NOT NULL,
    subtitle VARCHAR(255),
    slug VARCHAR(280) NOT NULL UNIQUE,
    summary TEXT,
    content TEXT NOT NULL,
    content_type VARCHAR(30) DEFAULT 'news' CHECK (content_type IN ('news', 'opinion', 'report', 'video', 'infographic', 'interview')),
    status VARCHAR(20) DEFAULT 'draft' CHECK (status IN ('draft', 'published', 'scheduled', 'archived')),
    category_id INTEGER NOT NULL,
    author_id INTEGER NOT NULL,
    source_id INTEGER DEFAULT NULL,
    featured_media_id INTEGER DEFAULT NULL,
    is_breaking BOOLEAN DEFAULT 0,
    is_featured BOOLEAN DEFAULT 0,
    views_count INTEGER DEFAULT 0,
    published_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (category_id) REFERENCES categories(category_id) ON DELETE RESTRICT,
    FOREIGN KEY (author_id) REFERENCES authors(author_id) ON DELETE RESTRICT,
    FOREIGN KEY (source_id) REFERENCES sources(source_id) ON DELETE SET NULL,
    FOREIGN KEY (featured_media_id) REFERENCES media(media_id) ON DELETE SET NULL
);

-- جدول الربط المتعدد بين الأخبار والوسوم (Article Tags)
CREATE TABLE article_tags (
    article_id INTEGER NOT NULL,
    tag_id INTEGER NOT NULL,
    PRIMARY KEY (article_id, tag_id),
    FOREIGN KEY (article_id) REFERENCES articles(article_id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags(tag_id) ON DELETE CASCADE
);

-- ========================================================
-- 6. جدول التفاعلات والتعليقات (Comments & Reactions)
-- ========================================================
CREATE TABLE comments (
    comment_id INTEGER PRIMARY KEY AUTOINCREMENT,
    article_id INTEGER NOT NULL,
    user_id INTEGER DEFAULT NULL, -- متاح للزوار المسجلين أو الزوار العاديين
    guest_name VARCHAR(100),
    guest_email VARCHAR(150),
    parent_id INTEGER DEFAULT NULL, -- للردود الشجرية
    content TEXT NOT NULL,
    status VARCHAR(20) DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'rejected', 'flagged')),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (article_id) REFERENCES articles(article_id) ON DELETE CASCADE,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE SET NULL,
    FOREIGN KEY (parent_id) REFERENCES comments(comment_id) ON DELETE CASCADE
);

CREATE TABLE reactions (
    reaction_id INTEGER PRIMARY KEY AUTOINCREMENT,
    article_id INTEGER NOT NULL,
    user_id INTEGER DEFAULT NULL,
    ip_address VARCHAR(45) NOT NULL, -- لتفادي تكرار التصويت من غير المسجلين
    reaction_type VARCHAR(20) NOT NULL CHECK (reaction_type IN ('like', 'dislike', 'important', 'analytical')),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (article_id) REFERENCES articles(article_id) ON DELETE CASCADE,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE SET NULL
);

-- ========================================================
-- 7. جدول المفضلة وسجل القراءة (Bookmarks & History)
-- ========================================================
CREATE TABLE bookmarks (
    user_id INTEGER NOT NULL,
    article_id INTEGER NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (user_id, article_id),
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE,
    FOREIGN KEY (article_id) REFERENCES articles(article_id) ON DELETE CASCADE
);

-- ========================================================
-- 8. جدول الأخبار العاجلة والإشعارات (Breaking & Notifications)
-- ========================================================
CREATE TABLE breaking_news (
    breaking_id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(255) NOT NULL,
    article_id INTEGER DEFAULT NULL, -- اختياري لرابط المقال المفصل
    is_active BOOLEAN DEFAULT 1,
    expires_at DATETIME NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (article_id) REFERENCES articles(article_id) ON DELETE SET NULL
);

-- ========================================================
-- 9. جدول الإعلانات وسجلات النظام (Ads & System Logs)
-- ========================================================
CREATE TABLE ads (
    ad_id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(100) NOT NULL,
    placement_code VARCHAR(50) NOT NULL, -- e.g. 'homepage_top', 'article_sidebar'
    ad_type VARCHAR(30) NOT NULL CHECK (ad_type IN ('image', 'script', 'html')),
    content TEXT NOT NULL, -- رابط الصورة أو كود JS الإعلاني
    is_active BOOLEAN DEFAULT 1,
    start_date DATETIME,
    end_date DATETIME,
    clicks_count INTEGER DEFAULT 0,
    impressions_count INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE system_logs (
    log_id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER DEFAULT NULL,
    action VARCHAR(100) NOT NULL,
    details TEXT,
    ip_address VARCHAR(45),
    user_agent TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE SET NULL
);

-- ========================================================
-- إنشاء الفهارس لتحسين كفاءة البحث والاستعلامات (Indexing Strategy)
-- ========================================================
CREATE INDEX idx_articles_slug ON articles(slug);
CREATE INDEX idx_articles_status_published ON articles(status, published_at);
CREATE INDEX idx_articles_category ON articles(category_id);
CREATE INDEX idx_articles_author ON articles(author_id);
CREATE INDEX idx_comments_article ON comments(article_id, status);
CREATE INDEX idx_breaking_active ON breaking_news(is_active, expires_at);
CREATE INDEX idx_tags_slug ON tags(slug);

```

## 3. المعمارية البرمجية للـ Backend وخرائط الـ RESTful APIs

### هيكلية المشروع (Folder Directory Structure)

يعتمد تطبيق **Express.js** على نمط معمارية **MVC (Model-View-Controller)** مُحدث مع تقديم طيقة خدمات مخصصة (Service Layer) للتنظيم البرمجي ورفع التكافؤ.

```text
news-platform-backend/
├── config/
│   ├── database.js          # تهيئة الاتصال بـ SQLite
│   ├── helmet.js            # إعدادات أمان Helmet
│   └── constants.js         # الثوابت الموحدة للنظام
├── controllers/
│   ├── authController.js    # تحكم المصادقة والمستخدمين
│   ├── articleController.js # تحكم إدارة المقالات والأخبار
│   ├── categoryController.js# تحكم التصنيفات
│   ├── commentController.js # تحكم التعليقات والتفاعلات
│   ├── ingestionController.js# تحكم الاستيراد الآلي JSON
│   ├── adminController.js   # تحكم الإشراف والمؤشرات
│   └── mediaController.js   # تحكم رفع واستعراض الملفات
├── middlewares/
│   ├── authMiddleware.js    # التحقق من صحة JWT Token
│   ├── roleCheck.js         # فحص الأدوار والصلاحيات (RBAC)
│   ├── uploadMiddleware.js  # تهيئة وتصفية Multer
│   ├── rateLimiter.js       # حماية الحدود المسموحة للطلبات
│   └── errorHandler.js      # التعامل الموحد مع الأخطاء البرمجية
├── models/                  # المخططات والاستعلامات المباشرة لـ SQLite
│   ├── userModel.js
│   ├── articleModel.js
│   ├── commentModel.js
│   └── mediaModel.js
├── routes/                  # تحديد مسارات API RESTful
│   ├── authRoutes.js
│   ├── articleRoutes.js
│   ├── categoryRoutes.js
│   ├── commentRoutes.js
│   ├── ingestionRoutes.js
│   └── adminRoutes.js
├── services/                # إدارات العمليات المعقدة والتكامل الخارجي
│   ├── jsonParserService.js # تحليل واستيراد ملفات JSON

├── public/
│   └── uploads/             # مجلد استضافة وسائط Multer المقسم تاريخياً
│       ├── images/
│       └── videos/
├── .env.example             # متغيرات البيئة الاسترشادية
├── package.json
└── server.js                # نقطة الانطلاق لتشغيل خادم Node.js

```

## 4. الحلول التقنية وأمان النظام (Technical Strategy & Security)

### إدارة الجلسات والصلاحيات (Authentication & RBAC)

* **المصادقة الهجينة (JWT Authentication Architecture):**
* يتم الاعتماد على رمز **JSON Web Token (JWT)** لتوفير صلاحية الوصول للـ API بدون حالة على الخادم (Stateless).
* تشفير الرمز باستخدام خوارزمية `HS256` وإدراج المكونات التالية في الـ Payload: `userId`, `roleId`, `email`.
* يتم حظر الرموز المنتهية عبر حفظ تاريخ تسجيل الخروج في الجدول أو تطبيق إستراتيجية Refresh Tokens عبر `HttpOnly Cookie` لضمان عدم وصول سكريبتات الشاشة (XSS) إليها.


* **التحكم بالوصول القائم على الأدوار (Role-Based Access Control - RBAC):**
* **Admin:** صلاحيات كاملة على النظام وإدارات المستخدمين والسجلات وتهيئة API.
* **Editor:** إنشاء، نشر، تعديل، أرشفة المقالات، إدارة العاجل، وتدقيق التعليقات.
* **Reporter:** كتابة الأخبار والتقارير وتحميل الوسائط بدون تفعيل قرار النشر المباشر (تظل بحالة `draft` أو `pending_review`).
* **User:** تصفح الموقع، التعليق، التفاعل، وحفظ المفضلة.

### نظام رفع الوسائط (Multer Pipeline & Storage)

* **هيكلية التخزين الموزعة:**
يتم توزيع الملفات داخل المجلد `public/uploads/` وفق تقسيم زمني لتفادي تكدس آلاف الملفات داخل المجلد الواحد:
`public/uploads/YYYY/MM/filename-uuid.ext`
* **آلية التسمية الفريدة والتصفية:**
توليد أسماء الملفات باستخدام **UUID v4** متبوعة بالامتداد الأصلي لمنع تعارض الأسماء والتغطية الحادّة على الملفات القديمة.
* **تصفية أنواع الميمات (MIME Type Validation):**

```javascript
const multer = require('multer');
const path = require('path');
const crypto = require('crypto');

// تحديد الامتدادات وأنواع الملفات المقبولة
const ALLOWED_MIME_TYPES = {
  'image/jpeg': 'jpg',
  'image/png': 'png',
  'image/webp': 'webp',
  'video/mp4': 'mp4'
};

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    const year = new Date().getFullYear();
    const month = String(new Date().getMonth() + 1).padStart(2, '0');
    const uploadPath = path.join(__dirname, `../public/uploads/${year}/${month}`);
    cb(null, uploadPath);
  },
  filename: (req, file, cb) => {
    const uniqueSuffix = crypto.randomUUID();
    const ext = ALLOWED_MIME_TYPES[file.mimetype];
    cb(null, `${uniqueSuffix}.${ext}`);
  }
});

const fileFilter = (req, file, cb) => {
  if (ALLOWED_MIME_TYPES[file.mimetype]) {
    cb(null, true);
  } else {
    cb(new Error('نوع الملف غير مدعوم! يسمح فقط بصيغ JPG, PNG, WEBP, MP4.'), false);
  }
};

const upload = multer({
  storage: storage,
  fileFilter: fileFilter,
  limits: { fileSize: 15 * 1024 * 1024 } // الحد الأقصى 15 ميجابايت
});

module.exports = upload;

```

### تكامل الاستيراد الآلي للمحتوى (Automated JSON Ingestion Engine)

1. **الاستقبال والتنقية:** استقبال حزمة الأخبار عبر نقطة التوصيل `/api/v1/admin/ingest/json`.
2. **مطابقة الحقول (Mapping Pipeline):** مطابقة حقول JSON الواردة مع بنية جدول الأخبار:
* `title` -> `articles.title`
* `body` -> `articles.content`
* `category_slug` -> البحث عن `category_id` المقابل في الجدول.


3. **منع التكرار (Deduplication Check):** مقارنة قيمة الـ Slug أو العنوان التراكمي (Hash) لمنع إدخال ذات الخبر مرتين.
4. **معالجة وحفظ الصور:** سحب الصور المرفقة بروابط خارجية وتنظيف البيانات المتاحة ثم تخزين الخبر بحالة default = `draft` أو `published` بحسب صلاحية مصدر الإمداد.

### استراتيجيات تحسين الأداء والأمان (Performance & Security Rules)

#### 1. تحسين الأداء والتخزين المؤقت (Performance & Caching)

* **SQLite Optimization:**
* تفعيل وضع **WAL (Write-Ahead Logging)** لرفع سرعة العمليات والتزامن بين القراءة والكتابة:
`PRAGMA journal_mode = WAL;`
* استخدام الاستعلامات المجهزة مسبقاً (Prepared Statements) للحد من زمن تفسير كود SQL.


* **إستراتيجية Caching لمحتوى الأخبار:**
* استخدام ذاكرة إنتاجية متداخلة في التطبيق (In-Memory Caching مثل `node-cache`) لحفظ نتائج الأخبار الأكثر قراءة والهيكل العام للتصنيفات والتغذية المباشرة لمدة (5 دقائق)، وتقليل الاستعلامات على SQLite بنسبة تصل إلى 80%.


* **الضغط وضغط الوسائط (Gzip / Brotli):**
* تفعيل وحدة `compression` في Express لضغط كافة استجابات JSON وHTML لتقليل استهلاك النطاق الترددي (Bandwidth).



#### 2. تعزيز أمان التطبيق (Application Security Rules)

```javascript
const express = require('express');
const helmet = require('helmet');
const cors = require('cors');
const rateLimit = require('express-rate-limit');

const app = express();

// 1. تعزيز ترويسات الأمان عبر Helmet
app.use(helmet());

// 2. التحكم في سياسة CORS
const corsOptions = {
  origin: process.env.CLIENT_URL || 'https://example.com',
  methods: ['GET', 'POST', 'PUT', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization'],
  credentials: true
};
app.use(cors(corsOptions));

// 3. حماية حدود الطلبات (Rate Limiting) لمنع هجمات DoS / Bruteforce
const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // نافذة 15 دقيقة
  max: 300, // حد أقصى 300 طلب لكل IP
  message: { error: 'تجاوزت الحد المسموح من الطلبات، يرجى المحاولة لاحقاً.' }
});

app.use('/api/', apiLimiter);

```

* **الحماية من SQL Injection:**
الاعتماد التام على الممر الآمن للمتغيرات (Parameterized Queries) المتاحة عبر محرّك SQLite وعدم دمج النصوص مباشرةً داخل الاستعلامات.
* **الحماية من XSS (Cross-Site Scripting):**
تنقية كود HTML المدخل عبر المحرر الإخباري بـ Backend باستخدام مكتبات التطهير (مثل `sanitize-html`) وتفادي تنفيذ السكريبتات الخبيثة في التعليقات.
* **تأمين البيئة (Environment Variables):**
حفظ مفاتيح التشفير، منافذ الخدمة، ومسارات قواعد البيانات داخل ملف `.dotenv` محمي وخارج النطاق المتاح في Git Repository.
